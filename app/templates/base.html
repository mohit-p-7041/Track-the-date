{# The home-screen button. Without apple-touch-icon, an iPad uses a *screenshot of the page* as the icon — ten iPads, ten different blurry buttons. The title is set separately because iOS would otherwise label it with the page title, which is different on every screen. The manifest is the same thing for Chrome on the Android scanner phone. All of it lives under /static, which is public, so a device that has not signed in yet can still fetch the icon. #} {# Every icon in the app, defined once and referenced with . A sprite rather than inline SVG per button because the Due screen can carry forty rows with two icons each, and 300 bytes a glyph adds up on shop WiFi; a is about twenty. No `role` attribute anywhere near these: the settings screen asserts that the word never appears in its HTML, and an ARIA role would put it there. `aria-hidden` on the icon and a real word beside it does the same job. #}
