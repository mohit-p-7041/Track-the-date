# Future ideas

Things wanted eventually, but not now. Nothing here is scheduled, and nothing here should be
built because it appeared in this file — an idea moves to `docs/BACKLOG.md` with acceptance
criteria before anyone writes code for it.

This is deliberately separate from the **Not being built** list at the bottom of
`docs/BACKLOG.md`. That list is closed questions, recorded so they don't get re-proposed. This
one is open questions, parked.

Ideas come from Mohit, who works the shop. When one lands here, record what problem it solves in
the aisle, not just the feature — the reason survives longer than the idea does, and it is what
decides the design later.
